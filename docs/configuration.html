Configuration System

Peek Shooter uses a data-driven configuration system where all game mechanics are defined in centralized config objects. This eliminates magic numbers and makes balancing easy.

📁 Config Files

🔫
WeaponConfig
src/config/WeaponConfig.js
All 5 weapon definitions with damage, fire rate, recoil patterns, and ADS settings.
💥
DamageConfig
src/config/DamageConfig.js
Body part damage values, multipliers, health settings, and debug colors.
⚡
PhysicsConfig
src/config/PhysicsConfig.js
Movement speeds, mouse sensitivity, particle physics, and network rates.
🗺️
MapConfig
src/config/MapConfig.js
Map layouts, cover positions, lighting setups, and spawn points.

🛠️ Using Configs

Accessing Configuration Values

// Get weapon config const weapon = WeaponConfig.getWeapon('assault_rifle'); console.log(weapon.damage.base); // 15 console.log(weapon.fireRate.rpm); // 600 // Get damage for body part const damage = DamageConfig.getDamage('head'); // 25 // Get physics value const crouchSpeed = PhysicsConfig.player.crouchSpeed; // 3.0 // Get map data const map = MapConfig.getMap('arena'); console.log(map.floor.width); // 30

Benefits of Data-Driven Design

  • No Magic Numbers: All values have clear names and documentation
  • Easy Balancing: Change one value to adjust game feel
  • Consistency: Same values used everywhere they're needed
  • Extensibility: Add new weapons/maps by adding config entries
  • Debugging: Easy to log and inspect current config state
