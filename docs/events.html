Event System

The EventBus provides a central pub/sub system for decoupling game systems. Any component can emit events without knowing who's listening, and any system can subscribe to events without knowing who emits them.

📖 API Reference

EventBus.on(event, callback, context?)
Subscribe to an event. Returns an unsubscribe function.
event string Event name (e.g., 'weapon:fired')
callback function Function called when event fires
context object? Optional 'this' context for callback
EventBus.emit(event, data)
Emit an event to all subscribers.
event string Event name to emit
data object Data payload to send to listeners
EventBus.once(event, callback, context?)
Subscribe to an event for one-time execution only.
EventBus.off(event, callback)
Unsubscribe a specific callback from an event.

💡 Usage Example

// Subscribe to events const unsubscribe = EventBus.on(GameEvents.HIT_OPPONENT, (data) => { console.log(`Hit ${data.bodyPart} for ${data.damage} damage`); // Play hit sound AudioSystem.playHitMarker(); // Show UI feedback showHitMarker(data.bodyPart); }); // Emit events EventBus.emit(GameEvents.HIT_OPPONENT, { bodyPart: 'head', damage: 25, point: hitPoint, direction: shotDirection, }); // Unsubscribe when done unsubscribe(); // Or use once() for one-time listeners EventBus.once(GameEvents.GAME_START, () => { console.log('Game started!'); });

📊 Event Data Structures

HIT_OPPONENT Event

{ bodyPart: 'head', // 'head' | 'chest' | 'belly' | 'arm' damage: 25, // Damage amount point: Vector3, // World hit position direction: Vector3, // Shot direction distance: 12.5, // Distance to target hitObject: Mesh, // Three.js mesh that was hit opponent: OpponentPlayer // Opponent entity }

HEALTH_CHANGED Event

{ entity: Entity, // Entity whose health changed previousHealth: 100, // Health before change currentHealth: 75, // Health after change maxHealth: 100, // Maximum health delta: -25 // Change amount (negative = damage) }

WEAPON_FIRED Event

{ timestamp: 1705432100000, // When shot was fired weapon: 'assault_rifle', // Weapon ID position: Vector3, // Camera position direction: Vector3 // Shot direction }
