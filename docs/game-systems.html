Game Systems

Peek Shooter uses dedicated systems for specific game functionality. Each system is a singleton that handles a particular aspect of gameplay - shooting, audio, and visual effects.

🎯 ShootingSystem

The ShootingSystem processes shots in distinct phases for clarity and maintainability.

🔫
Prepare
Audio, recoil, events
📡
Raycast
Ray intersection
🎯
Process
Hit detection
💥
Effects
Visual feedback

Phase 1: Prepare Shot

  • Emit WEAPON_FIRED event
  • Play gunshot audio via AudioSystem
  • Apply weapon recoil to camera
  • Send network shoot message

Phase 2: Perform Raycast

  • Create ray from camera center (screen center)
  • Store ray origin and direction
  • Return raycast result for hit processing

Phase 3: Process Hits

  • Check opponent intersection (multiplayer)
  • Check practice target intersection (offline)
  • Check environment intersection (walls, cover)
  • Apply damage and emit events

Phase 4: Create Effects

  • Blood splatter particles (opponent hits)
  • Blood decals on surfaces
  • Bullet hole decals (environment)
  • Hit marker UI feedback

Hit Priority System

1
Opponent Hit
Check if ray intersects opponent mesh. If hit, determine body part and apply damage.
2
Target Hit
Check practice targets in offline mode. Award points on hit.
3
Environment Hit
Check walls, cover, and other scenery. Create bullet hole decal.
// ShootingSystem main entry point shoot(context) { const { gameState, netState, targets } = context; // Phase 1: Prepare the shot const shotData = this.prepareShot(gameState); // Phase 2: Perform raycast const raycastResult = this.performRaycast(); // Phase 3: Process hits in priority order let result = null; // Priority 1: Check opponent if (netState?.gameMode === 'online') { result = this.handleOpponentHit(raycastResult, netState); if (result?.hit) return result; } // Priority 2: Check targets if (targets?.length > 0) { result = this.handleTargetHit(raycastResult, targets); if (result?.hit) return result; } // Priority 3: Check environment return this.handleEnvironmentHit(raycastResult); }

Tournament Flow

1
Enable Tournament Mode
Host enables tournament mode and selects kill target in the online menu before starting.
2
Settings Sync
When opponent joins, tournament settings are automatically synced via tournament_mode message.
3
Live Scoreboard
HUD displays "First to X" with remaining kills needed for each player.
4
Victory & Rematch
Winner declared when target reached. Both players see end overlay with rematch option.
// Tournament state in netState netState = { tournamentMode: false, // Is tournament mode active? tournamentKillsToWin: 5, // Target kills (3, 5, 7, 10, 15) }; // Check win condition after each kill function checkTournamentWin() { if (!netState.tournamentMode) return false; const myScore = netState.myKills; const opponentScore = netState.opponentKills; if (myScore >= netState.tournamentKillsToWin) { showTournamentEnd(true); // Victory! } else if (opponentScore >= netState.tournamentKillsToWin) { showTournamentEnd(false); // Defeat } } // Sync tournament settings to joiner sendPeerMessage({ type: 'tournament_mode', enabled: netState.tournamentMode, killsToWin: netState.tournamentKillsToWin });

// AudioSystem - Procedural sound generation const AudioSystem = { audioContext: null, masterGain: null, muted: false, init() { this.audioContext = new (window.AudioContext || window.webkitAudioContext)(); this.masterGain = this.audioContext.createGain(); this.masterGain.connect(this.audioContext.destination); }, // 3-layer gunshot: crack + body + thump playGunshot() { const ctx = this.audioContext; const now = ctx.currentTime; // Layer 1: High-frequency crack const crack = ctx.createOscillator(); crack.type = 'sawtooth'; crack.frequency.value = 2000; // ... envelope and connect // Layer 2: Mid-frequency body const body = ctx.createOscillator(); body.type = 'square'; body.frequency.value = 150; // Layer 3: Low-frequency thump const thump = ctx.createOscillator(); thump.type = 'sine'; thump.frequency.value = 60; }, };

✨ EffectsSystem

🩸
Blood Splatter

Particles spray from hit point in direction of shot. 8-15 particles with random spread, affected by gravity, lifetime 0.5-1.5 seconds.

Click to demo
🔴
Blood Decal

Stain applied to surfaces behind hit point. Random rotation, size variation 0.1-0.3 units, slight offset to prevent z-fighting.

⚫
Hit Mark

Bullet hole decal on environment surfaces. Dark circular mark with centered hole, aligned to surface normal.

❌
Hit Marker UI

Screen center crosshair indicator. Flashes white on hit, red on headshot. Brief animation with CSS transitions.

// Main animation loop - game.js function animate() { requestAnimationFrame(animate); const now = performance.now(); const deltaTime = (now - lastTime) / 1000; lastTime = now; if (!gameState.isRunning) return; // 1. Update stance (crouch, lean, strafe) updateStance(deltaTime); // 2. Update camera position and rotation updateCamera(); // 3. Update weapon position (hip/ADS) updateWeaponPosition(); // 4. Update opponent mesh from network state if (netState.opponent) { netState.opponent.update(deltaTime); updateOpponentMesh(deltaTime); } // 5. Update blood particles updateBloodParticles(deltaTime); // 6. Update recoil recovery updateRecoil(deltaTime); // 7. Send network state (60Hz) sendStateUpdate(); // 8. Render the scene renderer.render(scene, camera); }
