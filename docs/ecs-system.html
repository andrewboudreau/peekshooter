Entity-Component-System

Peek Shooter uses a composition-based ECS architecture where game objects (Entities) are built by attaching reusable Components. This approach promotes code reuse, separation of concerns, and makes it easy to add new behaviors without modifying existing code.

📦 Base Entity Class

The Entity class is the foundation for all game objects. It manages a collection of components and provides methods for adding, removing, and querying them.

class Entity { static nextId = 0; constructor(type = 'entity') { this.id = Entity.nextId++; // Unique identifier this.type = type; // 'player', 'opponent', etc. this.components = new Map(); // Component storage this.tags = new Set(); // For querying this.active = true; // Is entity active? } // Add a component to this entity addComponent(component) { const name = component.constructor.name; this.components.set(name, component); component.entity = this; component.onAttach(this); return this; // Enable chaining } // Get a component by class name getComponent(name) { return this.components.get(name) || null; } // Update all components update(deltaTime) { if (!this.active) return; for (const component of this.components.values()) { if (component.active) { component.update(deltaTime); } } } }

Player Entity

class Player extends Entity { constructor(slot) { super('player'); this.slot = slot; // 0 or 1 this.weaponHand = 'right'; this.currentWeapon = 'assault_rifle'; this.input = { // Input state forward: false, backward: false, left: false, right: false, leanLeft: false, leanRight: false, }; // Add default components this.addComponent(new HealthComponent(100)); this.addComponent(new TransformComponent()); } // Get state for network transmission getNetworkState() { const transform = this.getComponent('TransformComponent'); const health = this.getComponent('HealthComponent'); return { crouch: transform.stance.crouch, lean: transform.stance.lean, strafe: transform.stance.strafe, lookYaw: transform.look.yaw, lookPitch: transform.look.pitch, weaponHand: this.weaponHand, weapon: this.currentWeapon, health: health.currentHealth, }; } }

Opponent Entity

class Opponent extends Entity { constructor(slot, scene) { super('opponent'); this.slot = slot; this.scene = scene; this.mesh = null; // THREE.Group for body this.weaponMesh = null; // Weapon mesh // Add components with HitboxComponent for hit detection this.addComponent(new HealthComponent(100)); this.addComponent(new TransformComponent()); this.addComponent(new HitboxComponent()); this.createMesh(); // Create 3D model this.setupHitboxes(); // Setup body part hitboxes } // Apply network state with interpolation applyNetworkState(state) { const transform = this.getComponent('TransformComponent'); transform.setTargetStance({ crouch: state.crouch, lean: state.lean, strafe: state.strafe, }); transform.setLook(state.lookYaw, state.lookPitch); } }

🔍 Component Methods Reference

HealthComponent Methods

takeDamage(amount, options) Apply damage, returns {dealt, killed, blocked}
heal(amount) Restore health, returns actual amount healed
die(killer) Mark as dead, emit death events
respawn() Reset health and resurrect entity
get healthPercent Returns health as 0-1 percentage

TransformComponent Methods

setPosition(x, y, z) Set world position
setTargetStance(stance) Set interpolation target for stance
setLook(yaw, pitch) Set look direction
attachMesh(mesh) Link Three.js mesh to transform
isPeeking() Returns true if leaning/strafing out

HitboxComponent Methods

addPart(name, mesh, damage) Add a body part hitbox
raycast(raycaster) Check ray intersection, returns hit info
getDamage(bodyPart) Get damage value for body part
setDebug(show, scene) Toggle debug visualization
