Recoil System

Recoil follows a deterministic pattern based on shot count. Click "Fire Burst" to visualize the pattern.

// Recoil configuration in WeaponConfig.js recoil: { verticalBase: 0.025, // Base upward kick per shot verticalVariance: 0.008, // Random variance horizontalBase: 0, // Base horizontal (0 = none) horizontalVariance: 0.015, // Random left/right recovery: 4.0, // Return-to-center speed pattern: [ // Shot multipliers 1.0, 1.1, 1.2, 1.15, 1.1, 1.0, 0.95, 0.9 ], weaponKickBack: 0.03, // Visual weapon push-back weaponKickUp: 0.02, // Visual weapon rise }

WeaponFactory

All weapon models are procedurally generated using Three.js geometry. No external model files required.

// WeaponFactory usage const WeaponFactory = { // Create first-person weapon model createWeapon(weaponId) { const config = WeaponConfig.getWeapon(weaponId); const group = new THREE.Group(); // Create receiver (main body) const receiver = new THREE.Mesh( new THREE.BoxGeometry(0.04, 0.08, 0.25), new THREE.MeshStandardMaterial({ color: 0x222222 }) ); group.add(receiver); // Create barrel, stock, grip, etc... return group; }, // Create simplified third-person model createOpponentWeapon(weaponId) { return this.createWeapon(weaponId); } };

Controls

Left Click Fire weapon
Right Click Aim down sights (ADS)
1-5 Keys Switch weapons (1=Pistol, 2=SMG, 3=AR, 4=Shotgun, 5=Sniper)
R Key Reload (future feature)
B Key Toggle fire mode (Single/Burst/Auto)
