Network Architecture

Peek Shooter uses a peer-to-peer WebRTC architecture via PeerJS for real-time multiplayer gameplay. The network layer handles state synchronization at 60Hz, hit registration, and coordinate transformation between players on opposite sides of the arena.

Connection Flow

  1. Host creates room: Generates 4-character room code (e.g., "ABCD")
  2. PeerJS registers: Host registers as peekshooter-ABCD on signaling server
  3. Joiner connects: Enters code, connects to peekshooter-ABCD
  4. WebRTC established: ICE candidates exchanged, DataChannel opens
  5. Game starts: Both players spawn on opposite sides, state sync begins

📨 Message Protocol

Type Direction Frequency Description
state Bidirectional 60 Hz Player stance, look direction, weapon state
shoot Sender → Receiver On action Shot fired with hit point and target info
hit Shooter → Victim On hit Damage amount and body part hit
killed Victim → Shooter On death Confirmation of kill
reset Bidirectional On round end Health and state reset for new round

State Synchronization (60 Hz)

Player state is synchronized every frame to ensure smooth interpolation on the opponent's screen.

// State message structure { type: 'state', state: { crouch: 0.5, // 0 (standing) to 1 (crouched) lean: -0.3, // -1 (left) to 1 (right) strafe: 0.2, // -1 (left) to 1 (right) lookYaw: 0.15, // Horizontal look angle (radians) lookPitch: -0.08, // Vertical look angle (radians) weaponHand: 'right', // Current weapon hand weapon: 'assault_rifle', health: 85 } }

Hit Registration

Peek Shooter uses client-authoritative hit detection - the shooter's client determines hits.

// Hit message - sent when shooter confirms hit { type: 'hit', damage: 25, // Damage amount bodyPart: 'head' // Body part hit } // Killed message - sent when victim's health depletes { type: 'killed' }

🗺️ Coordinate Transformation

Players face each other from opposite ends of the arena. When receiving opponent positions, coordinates must be transformed to match the local player's perspective.

🧍
🧍
z = 0 (Player 0 spawn)
z = -15 (Player 1 spawn)
Coordinate Transformation for Received Data:
transformedX = -receivedX
transformedZ = -15 - receivedZ
// handleOpponentShot - Transform received hit coordinates function handleOpponentShot(opponent, shotData) { // Transform coordinates to local space const transformedX = -shotData.hitX; const transformedZ = -15 - shotData.hitZ; // Now we can render effects at the correct position const hitPoint = new THREE.Vector3( transformedX, shotData.hitY, transformedZ ); createBloodSplatter(hitPoint, direction); }

🖥️ Socket.io Fallback Server

server.js Architecture

The Socket.io server provides a fallback for environments where WebRTC P2P fails. It handles room management, state relay, and authoritative hit validation.

// Server-side Room and Player classes class Player { constructor(id, slot) { this.id = id; this.slot = slot; // 0 or 1 this.state = { crouch: 0, lean: 0, strafe: 0, lookYaw: 0, lookPitch: 0, weaponHand: 'right', health: 100 }; } } class Room { constructor(id) { this.id = id; this.players = new Map(); this.state = 'waiting'; // waiting | playing | finished this.scores = [0, 0]; } }

📈 Network Performance

Optimization Strategies

  • State Interpolation: Opponent positions are interpolated at 15x speed to smooth network jitter
  • Delta Compression: Only changed state values need to be sent (implicit in message structure)
  • Fixed Update Rate: 60Hz ensures consistent behavior across different frame rates
  • Client-Authoritative Hits: Reduces perceived latency for the shooter
  • Reliable DataChannel: All messages delivered in order via reliable mode
// OpponentPlayer.update() - Interpolation toward target state update(deltaTime) { const lerpSpeed = 15; // Interpolation multiplier const t = Math.min(1, lerpSpeed * deltaTime); // Smoothly interpolate all stance values this.state.crouch += (this.targetState.crouch - this.state.crouch) * t; this.state.lean += (this.targetState.lean - this.state.lean) * t; this.state.strafe += (this.targetState.strafe - this.state.strafe) * t; this.state.lookYaw += (this.targetState.lookYaw - this.state.lookYaw) * t; this.state.lookPitch += (this.targetState.lookPitch - this.state.lookPitch) * t; }
